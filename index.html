Pengaturan Portal

Portal ini terhubung ke Web App Google Apps Script Anda. Masukkan URL-nya satu kali:

  1. Google Spreadsheet → Extensions → Apps Script
  2. Deploy → Manage deployments (atau New deployment → Web app)
  3. Salin URL web app, tempel di bawah

Tips: agar semua pengguna langsung terhubung (tanpa isi manual), tempel URL yang sama ke file web/config.js di GitHub, lalu push.
